# Beekeeping Online Store


Ein Online-Shop für Imkereiprodukte und Imkereibedarf, den ich als eigenes Full-Stack-Projekt entwickle. Kundinnen und Kunden können Produkte ansehen, nach Kategorien filtern und eine Bestellung aufgeben. Im Adminbereich lassen sich eingegangene Bestellungen einsehen.

## Technologien

- **Frontend:** Angular, TypeScript, HTML und CSS
- **Backend:** PHP und Symfony
- **Datenbank:** MySQL

## Was ich umgesetzt habe

- Produktübersicht mit Kategoriefilter und Produktdetailseiten
- Bestellfunktion mit Speicherung der Bestellungen in MySQL
- API-Endpunkt für die Bestellübersicht im Adminbereich
